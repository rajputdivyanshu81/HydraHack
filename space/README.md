# DesirePath: live demo

A knowledge graph on HydraDB that repairs itself where users ask. HydraDB 0.4.0 and the demo run together in this
Space. The graph starts with half its edges deleted (MetaQA movie graph); ask a question, see the traversal and
the gaps, give feedback, and watch the graph heal and the answer improve.

Claude responses are replayed from a recorded cache, so the demo needs no API key and behaves exactly as in the
reported experiments. Source and results: https://github.com/rajputdivyanshu81/HydraHack
